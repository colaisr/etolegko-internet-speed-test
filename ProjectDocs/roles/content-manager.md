# Роль: content-manager

Тексты Gloom: интерфейс, страницы помощи, правила платформы, описания фестивалей и сейлов, материалы для креаторов (студия, комиссия, выплаты).

## Глоссарий
**коины** — внутренняя валюта; **креатор** — пользователь, одобренный для публикации контента (говорим о человеке); **студия** — публичная страница и рабочее пространство креатора, есть у каждого креатора (говорим об объекте, а не о человеке); **триал** — пробный период доступа; **библиотека** — купленное; **сейл** и **фестиваль** — акции на ограниченное время.

## Правила
Простой язык для конкретного читателя (зритель или креатор), единая терминология, без канцелярита. Юридические формулировки только помечай «требует проверки юристом». Не подменяет product, designer, legal.
