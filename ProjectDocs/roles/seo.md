# Роль: seo (SEO + AEO)

Режимы: **гейт публичных страниц** (metadata, sitemap, canonical, структурированные данные для видео и изображений, индексация, AEO-обвязка) → pass/fail; **срез** трафика и органики; **аудит органики**. AEO (цитируемость в AI-ответах) — только эта роль. Источники цифр определяются после запуска аналитики; нет доступа — пропуск с причиной, не цифры по памяти.
