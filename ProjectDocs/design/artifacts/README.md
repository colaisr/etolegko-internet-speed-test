# Артефакты дизайна: как хранить и обновлять

> **Правило:** источник правды — **файлы в репозитории**. Опубликованные страницы Claude (Artifacts) — только удобный просмотр, копия. Всё, что нужно агенту в Cursor или Claude Code, лежит в git как обычные файлы.

## Почему так

Claude умеет собирать прототипы, моодборды и референсы как самостоятельные страницы. Но если они живут только в интерфейсе Claude, Cursor и другие агенты их не видят и не могут обновить. Поэтому каждый артефакт сначала создаётся как файл в проекте, и только потом, при желании, публикуется.

## Структура

| Путь | Что хранить | Формат |
| --- | --- | --- |
| `ProjectDocs/design/*.md` | Бренд-платформа, голос, бренд-бук, дизайн-система, IA и flows, каталог состояний | Markdown |
| `ProjectDocs/design/artifacts/prototypes/` | Кликабельные прототипы и макеты экранов | Один самодостаточный `.html` на прототип |
| `ProjectDocs/design/artifacts/references/` | Моодборды, разбор референсов, скриншоты, заметки о них | `.md` + изображения |
| `ProjectDocs/design/artifacts/assets/` | Логотипы, иконки, ключевой арт | SVG / PNG |
| `ProjectDocs/design/artifacts/INDEX.md` | Реестр всех артефактов | Markdown |

Токены дизайн-системы (цвета, шрифты, отступы) после выбора стека выносятся в код-файл (например JSON/CSS-переменные), а в `design-system.md` остаётся ссылка и пояснения. Так токены читаются и человеком, и агентом, и приложением.

## Правила для агентов (Claude Code и Cursor)

1. **Создание.** Прототип пишется в `.html`-файл в `prototypes/`. Без внешних зависимостей, кроме разрешённых CDN, чтобы файл открывался двойным кликом.
2. **Публикация (по желанию).** Из Claude файл публикуется через инструмент Artifact с тем же `file_path`. Полученная ссылка записывается в `INDEX.md`. Публикуй только по просьбе владельца.
3. **Обновление.** Сначала правится файл в репозитории, затем перепубликация в тот же URL. Никогда не правь только опубликованную копию.
4. **Реестр.** Каждый артефакт — строка в `INDEX.md`: путь, назначение, статус, дата, ссылка на публикацию (если есть), связанные документы.
5. **Актуальность.** При изменении дизайн-системы или бренда агент находит затронутые артефакты по `INDEX.md` и обновляет их или ставит статус `устарел`.
6. **Статусы:** `черновик` / `утверждён` / `устарел`. Утверждает владелец.
7. **Чтение.** Cursor и Claude Code читают файлы напрямую. Если артефакт есть только как опубликованная страница, сначала скачать его в файл (Claude: `Artifact` с `action: read`) и положить в репозиторий.
