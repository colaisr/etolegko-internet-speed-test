# Бренд Legko / «Это Легко» (тестовое задание)

> **Статус:** актуален (2026-11-19). Референс: [etolegko.ru](https://etolegko.ru/), скриншоты владельца.

## Позиционирование в UI

Внутренний инструмент агентства **«Это Легко»** для байеров. Название продукта **Legko** созвучно бренду — в интерфейсе: логотип-намёк (куб/пиксели + «LEGKO» / «ЭТО ЛЕГКО»), не копировать весь маркетинговый сайт.

## Визуальный код сайта

| Элемент | Характеристика |
| --- | --- |
| Фон hero | Тёмный navy/black, «цифровой» фон |
| Акцент | **Лайм / chartreuse** — CTA, активные состояния, ключевые цифры |
| Текст на тёмном | Белый, uppercase в навигации |
| Светлые секции | Белый фон, чёрный текст, пунктирные/тонкие рамки карточек |
| Кнопки | Прямоугольные, **без скругления** (или max 2px), primary: лайм + чёрный текст, uppercase |
| Навигация | Активный пункт — **обводка/заливка лайма** |
| Тон | Техничный, уверенный, digital, «серьёзное агентство» |

## Ограничения

- Не маркетинговый лендинг: **рабочая панель** с таблицей и цифрами.
- Контраст и a11y: лайм на белом только для мелких акцентов; крупные CTA — как на сайте.
