# UX-принципы Legko

> **Статус:** актуален (2026-11-19). Обязательны для **всех итераций**; designer проверяет каждый change.

## 1. Рынок и аналоги (кратко)

| Продукт / паттерн | Что берём | Чего не берём |
| --- | --- | --- |
| **Keitaro admin** | Знакомые термины: кампания, поток, оффер, вес | Плотность, все экраны, мгновенный save |
| **Voluum / Binom / RedTrack** | Фокус на **кампании** и **ротации**, цифры крупно | Статистику, отчёты, многовкладочность |
| **Draft → Publish** (CMS, feature flags, Figma) | Черновик, превью изменений, явная публикация | Сложные approval workflows |
| **Internal tools** (Stripe Dashboard, Linear) | Статус-бейджи, первичное действие справа, понятные empty states | — |

**Позиция Legko:** не «ещё один трекер», а **симулятор сплита** с брендом агентства и **production-полировкой** для тестового.

## 2. Принципы (норматив)

| # | Принцип | Реализация |
| --- | --- | --- |
| P1 | **Статус раньше действия** | Бейдж «Синхронно / Черновик» виден без скролла |
| P2 | **Цифры — герой** | Колонка веса: крупный tabular-nums; сумма 100% рядом с таблицей |
| P3 | **Опасное — два шага** | Push только через modal **diff** |
| P4 | **Не врать про Keitaro** | Подсказка: «В трекере пока старая версия» при жёлтом |
| P5 | **Один главный поток** | Оффер-ротация — центр; служебный поток — сжатый |
| P6 | **Целостность бренда** | Только компоненты из [`design-system.md`](design-system.md) |
| P7 | **Desktop-first** | min-width 1024px; адаптив — после MVP |

## 3. Иерархия внимания (редактор)

1. Статус кампании + сумма весов  
2. Таблица офферов  
3. Push / Cancel  
4. Fetch, Add  
5. Мета (domain/group/source)

## 4. Микрокопия (тон)

- Коротко, по-русски, без жаргона кроме Keitaro/оффер/поток.
- Ошибки: **что случилось + что сделать** («Сумма 94% — добавьте вес или уберите pin»).

## 5. Чеклист designer на итерацию

- [ ] Новые UI — только токены/компоненты из design-system  
- [ ] Статусы draft/sync через `Badge`  
- [ ] Primary action = лайм `Button`  
- [ ] Таблица = `DataTable`  
- [ ] Деструктивное / Push = modal
