# Создаватель кампаний

> **Статус:** актуален (2026-11-19, фаза B закрыта). **Для MVP:** обязательно. Сводка: [`29-mvp-functional-description.md`](29-mvp-functional-description.md) §3.

## 1. Зачем пользователю

| Боль в Keitaro | Что даёт создаватель |
| --- | --- |
| Долго собирать 2 потока и фильтры | **Шаблон в один шаг** |
| Типовая ошибка geo / оффер | Превью схемы **до** Create |
| Непонятно, какой URL отдавать в сеть | **Ссылка кампании** на экране успеха |

После Create байер попадает в **редактор (симулятор сплита)** — там основная ценность.

## 2. Экран (логически)

- Поля: **название**, **geo**, **оффер** (поиск по имени/id).
- Блок **превью шаблона** (read-only): поток 1 `{geo}→Google`, поток 2 `остальной трафик→оффер {имя/id}`.
- Кнопка **Создать** (disabled пока невалидно / идёт запрос).
- После успеха: **результат** (см. §5) и CTA **Открыть в редакторе**.

Domain / group / source: **только чтение** из конфига компании (env); на Create и в шапке редактора — подпись «как заведено в компании», без дропдаунов в MVP ([`29` §10](29-mvp-functional-description.md)).

## 3. Ввод и норматив Keitaro

| Поле | Правило |
| --- | --- |
| Название кампании | Обязательно, не пустое |
| Geo-код | ISO-2, валидация формата |
| Оффер | Существующий в Keitaro (проверка при create) |

**Результат в Keitaro:**

1. **Поток 1** — трафик из geo → **Google**.
2. **Поток 2** — остальной трафик → **один выбранный оффер, 100%** (решение product 2026-11-19).
3. **Домен, группа, источник** — по API с дефолтами компании.

Мульти-оффер и делёжка % — только в **редакторе**.

## 4. Поведение системы (глазами байера)

| Шаг | Байер | Система |
| --- | --- | --- |
| Заполняет поля | Видит превью | — |
| Create | Ждёт | Keitaro: кампания + потоки; SQLite: локальная запись; UI: успех |
| Ошибка API | Видит причину | Keitaro без «половины» кампании (rollback) |
| «В редактор» | — | Открывает кампанию по локальному / keitaro id |

## 5. Экран успеха (ценность прозрачности)

Обязательно показать:

- Keitaro **campaign id**
- **Campaign URL** для трафика (копировать)
- Кратко: geo, оффер, domain, group, source
- Кнопка **Перейти в редактор**

## 6. Граничные случаи

| Случай | Поведение |
| --- | --- |
| Неверный offer / geo | Ошибка, форма сохраняется |
| Keitaro down | Ошибка + retry |
| Дубль имени (если Keitaro ругается) | Текст от API, подсказка сменить имя |
| Таймаут | Не оставлять локальную запись без подтверждённого keitaro id |

## 7. Вне MVP

Иной URL вместо Google, >2 потоков, CSV, клон кампании, правка шаблона в UI.
