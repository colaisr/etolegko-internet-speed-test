# Главная и навигация (F1)

> **Статус:** актуален (2026-11-19). Фича **F1** в [`30-mvp-features-and-acceptance.md`](30-mvp-features-and-acceptance.md).

## Ценность

Точка входа: **создать** новую связку или **вернуться** к недавней / известной по id — без полного каталога Keitaro.

## Экран Home

| Блок | Поведение |
| --- | --- |
| Hero | Одна фраза про симулятор сплита (бренд «Это Легко») |
| Primary CTA | «Создать кампанию» → Creator |
| Open by ID | Поле + «Open»; валидация «число / не пусто» |
| Недавние | Кампании из SQLite, сортировка по `updated_at` desc, max 10 |

### Недавние — что показываем

- Локальное имя (или keitaro name snapshot)
- Keitaro campaign id
- Бейдж: Синхронно / Черновик (из локального статуса)

Клик → Editor(id).

## Ошибки

| Ситуация | Сообщение |
| --- | --- |
| ID не найден в Keitaro | «Кампания не найдена» |
| ID не найден локально, но есть в Keitaro | Создать локальную оболочку и Fetch (решение E: lazy import) |

**Product (фаза D):** если кампания есть только в Keitaro — при первом Open **создаём** локальную запись и **Fetch** (иначе нельзя открыть чужие кампании теста). Зафиксировать в architecture E.

## Вне MVP

Список всех кампаний Keitaro, поиск, пагинация, избранное.
