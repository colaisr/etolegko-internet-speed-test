## Зачем видео

Эталон **части 2 ТЗ** — редактор потоков кампании. Часть 1 (создаватор) в видео только как пример готовой кампании в Keitaro.

## Модель данных (обёртка ≠ только Keitaro)

- У обёртки **своя БД** состояния; Keitaro — источник после **push**.
- Потоки **без офферов** (например geo → Google) при **Fetch Streams** подтягиваются как «пустые» потоки: **без парсинга** редиректов и фильтров, ничего не показывать пользователю про содержимое.
- Парсить и редактировать — только потоки **с офферами**.

## Fetch Streams

- Кнопка **Fetch Streams** (в транскрипте «FCH/F streams»): подтянуть потоки кампании из Keitaro.
- Офферы в offer-потоке отображаются; не-offer потоки — как заглушки.

## Добавление оффера

1. Выбор оффера: UI ищет через **API обёртки** (в видео — jQuery → бэкенд → Keitaro за списком офферов).
2. **Add** → в UI **пересчёт весов** (равномерно на все активные офферы; пример: 3→33%, 4→25%).
3. Поток **жёлтый** = есть неопубликованные изменения.
4. **Refresh** без push — в Keitaro по-прежнему старый набор (например 3 оффера).
5. **Push to Keitaro** — изменения уходят в Keitaro (веса и состав).

## Cancel (до push)

- Отмена снимает добавленные **до публикации** офферы из БД обёртки; привязки удаляются; поток снова **белый**.

## Удаление оффера (soft remove)

1. **Remove** → оффер серый, вес **0%**, поток жёлтый.
2. **Push** → оффер исчезает в Keitaro, в обёртке остаётся **в архиве** (removed), кнопка **Bring back**.

## Bring back

- Возврат removed-оффера → снова жёлтый поток → после **push** оффер снова в потоке Keitaro.

## Синхронизация при расхождении с Keitaro

- Если в Keitaro вручную удалили офферы и сделали **Fetch Streams** снова:
  - офферы, о которых знала обёртка, но которых нет в Keitaro → статус **removed** (серые), как после ручного remove;
  - доступен **Bring back**.

## Pin веса

- Оффер можно **запинить** на фиксированный % (пример 25%).
- При add/remove пересчитываются только **не запиненные** веса; запиненный не меняется.
- После push: запиненный вес в Keitaro сохраняется; остальные делят оставшуюся долю до 100%.

## Кнопки / состояния UI (для MVP)

| Состояние потока | Визуал | Смысл |
| --- | --- | --- |
| Синхронизирован | белый | нет локальных черновиков |
| Есть черновик | жёлтый | нужен push или cancel |
| Оффер active | обычный | в потоке, вес > 0 |
| Оффер removed | серый, 0% | soft-delete, bring back |

**Действия:** Fetch Streams, Add offer, Remove, Bring back, Pin weight, Push to Keitaro, Cancel.
