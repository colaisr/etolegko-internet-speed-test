## Контекст

Keitaro — рекламный трекер: конструктор ссылок, редиректы по правилам, статистика редиректов. В ТЗ приведён пример: поток по geo (например AU) → Google, остальные → офферы.

## Часть 1: «создаватор» кампаний

**Вход:**

- название кампании
- гео-код страны
- ID оффера в Keitaro

**Результат — кампания с:**

1. **Два потока:**
   - поток 1 — весь трафик из указанной страны → **Google**
   - поток 2 — остальной трафик → **выбранный оффер**
2. Настроенными **доменом, группой и источником** (через API Keitaro).

На странице Notion — скрин **примерного интерфейса** (поля + создание).

## Часть 2: редактор существующей кампании

- Добавлять и удалять **офферы** в кампании.
- Эталон поведения — видео: [keitaro wrapper - test](https://youtu.be/jNloscEWCjA).
- UI на усмотрение исполнителя; кнопки должны работать, **цифры — верные**.

## Документация и доступы

- Документация API Keitaro и API-ключ — в **админке Keitaro**.
- На самой Notion-странице **нет** хоста, логина, срока сдачи и требований к GitHub/README (могут быть в другом документе / переписке).

## Контекст вакансии (не часть ТЗ, справочно)

С родительской страницы: Django, Celery, Postgres, Redis, RabbitMQ, Docker; фронт сейчас html+jQuery, движение к Angular; опыт деплоя; уверенное использование AI-инструментов с пониманием кода.
