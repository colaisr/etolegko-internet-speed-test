# Редактор потоков и офферов

> **Обновлено:** 2026-11-19 · **Change:** stream-editor-offer-ops (F4)  
> **Замысел:** [PlanDocs/02-stream-offer-editor.md](../PlanDocs/02-stream-offer-editor.md) · **Спеки:** `stream-editor-fetch`, `stream-editor-offer-ops`

## 1. Что это и зачем

Редактор — **симулятор сплита**: байер видит потоки и меняет микс офферов **локально**, сверяясь с Keitaro через обновление снимка.

## 2. Как это работает сейчас

- **`/campaigns/{id}/editor`** — шапка (имя, Keitaro id, geo, status pill, URL с копированием), **Обновить из Keitaro**.
- После **create (F2)** потоки подтягиваются автоматически (`full_fetch`); если потоков нет — блок «Потоки ещё не загружены» и CTA обновления.
- **POST `/campaigns/{id}/fetch`** — перезагрузка потоков из Keitaro; при ошибке — сообщение на странице (например, кампания не найдена в API).
- **Служебный поток** — одна серая строка с lock (geo → Google), без деталей фильтра.
- **Оффер-поток** — таблица с Σ активных %, действиями:
  - **Добавить** оффер (поиск Keitaro или ID) → пересчёт %, поток **жёлтый** (`has_draft`), статус **Черновик**.
  - **Убрать** → 0%, статус removed, пересчёт active.
  - **Вернуть** → active + пересчёт.
  - **Закрепить %** / **Открепить** — фиксация доли; незакреплённые делят остаток (**largest remainder**, сумма 100%).
- Keitaro **не меняется** от этих операций до **Push (F5)**.
- **Push в Keitaro** и **Отменить изменения** — на экране, пока **недоступны** (F5/F6).

## 3. Кто что может

Один байер — полный доступ к экрану, Fetch и операциям с офферами при настроенном Keitaro API.

## 4. Правила и граничные случаи

- **Fetch** заменяет локальные потоки снимком Keitaro (без merge черновика — F7).
- Pin принимает целые проценты 1–99; сумма **активных** весов должна быть 100% для будущего Push.
- Добавление оффера требует существующего id в Keitaro (поиск показывает доступные офферы API-ключу).
- Кампания без Keitaro id или удалённая в трекере — fetch/операции с ошибкой.

## 5. Отличия от замысла (PlanDocs)

- **Push, Cancel, diff-модалка** — F5/F6 (ещё не в продукте).
- **Drift-merge** после ручных правок в Keitaro — F7.
- UI редактора доработан по design-system (command bar, `card--editor-lab`, иконки действий) сверх минимального wireframe.
