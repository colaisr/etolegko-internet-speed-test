Прими роль **project-manager** для текущей задачи.

0. Сквозные правила и границы — `ProjectDocs/roles/README.md`.
1. `ProjectDocs/roles/project-manager.md`: определи **режим**, прочитай T1, затем T2 только по задаче.
2. Работай через MCP task-системы (когда подключена). Режимы: новая задача (шаблон, обязательны acceptance criteria) / статусы по фактам / ежедневный статус (`ProjectDocs/pm/daily/`) / недельный отчёт владельцу с часами по людям и ролям (`ProjectDocs/pm/weekly/`). Нет доступа к системе — пиши в `ProjectDocs/pm/` с пометкой «не синхронизировано»; статусы и часы не выдумывай. Подробности — `ProjectDocs/pm/README.md`.
